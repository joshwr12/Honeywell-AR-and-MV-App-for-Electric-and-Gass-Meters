# Honeywell AR and MV App for Electric and Gass-Meters
# Task:
As a 5 member team, create an app that has augmented reality and machine vision capabilities. This app will detect and pop up ar ui overlay for Honeywell's gas and electric meters. This ui overlay will include documents, data sheets, and more meter information.
# Purpose:
To assist Honeywell's field service technicians in performing service and maintenance task on meters. This app will help reduce errors and improve work effeciency.
# Team Approach:
Divide task into sections:
  - AR and Overlay UI Creation
  - Machine Vision
  - AI Helper
  - Integration (Put all components together)
  - Testing
# Software Stack and Purpose:
  - Unity (ARKit and ARCore): The main software component that will tie all the components together. Also used for augmented reality capabilities and ui overlay creation.
  - Xcode: Builds the Unity project to Apple device to create a usable application
  - YOLOv8: Machine vision software used to detect if meter Honeywell's or not. It will also differentiate between electric and gas meters.
  - Botpress: AI helper used to aid workers and answer questions using provided meter documentation
